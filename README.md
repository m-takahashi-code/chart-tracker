# 新店チャート手配台帳

カラーチャート／ストーンチャート／サンプルオプションの新店舗向け作成・在庫振り分け状況を、会社のみんなで共有しながら管理するツールです。

## 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成する
2. `index.html` をアップロードする
3. Settings → Pages → Source を「Deploy from a branch」`main`/`root` に設定
4. `https://ユーザー名.github.io/リポジトリ名/` で公開される

## みんなでデータを共有するための設定（Firebase）

このアプリは「Firebase」というGoogleの無料データベースサービスと繋ぐことで、
**誰がどのパソコン・スマホから開いても同じデータが見える／編集できる**ようになります。

### 手順1：Firebaseプロジェクトを作る

1. ブラウザで **https://console.firebase.google.com** を開く
2. Googleアカウントでログイン（会社のGoogleアカウントでも個人のものでもOK）
3. 「**プロジェクトを作成**」をクリック
4. プロジェクト名を入力（例：`chart-tracker`）→「続行」
5. Google Analyticsの設定画面が出たら「**このプロジェクトでGoogleアナリティクスを有効にする**」のチェックを**外して**「プロジェクトを作成」
6. 数十秒待って「続行」

### 手順2：Realtime Databaseを有効にする

1. 左側メニューの「**構築**」→「**Realtime Database**」をクリック
2. 「**データベースを作成**」をクリック
3. ロケーションはそのままで「次へ」
4. セキュリティルールの選択で「**テストモードで開始する**」を選んで「有効にする」
   - ※テストモードは「誰でも読み書きできる」設定です。社内限定のツールなので許容していますが、
     URLを外部に広めないよう注意してください（詳しくは下記「セキュリティについて」参照）

### 手順3：接続用の設定値（config）を取得する

1. 画面左上の歯車アイコン ⚙️ →「**プロジェクトの設定**」をクリック
2. 下の方の「**マイアプリ**」欄で「**</>**」（ウェブ）のアイコンをクリック
3. アプリのニックネームを適当に入力（例：`chart-tracker-web`）→「アプリを登録」
4. 画面に表示される、以下のような形のコードをコピーする

   ```js
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "xxxxx.firebaseapp.com",
     databaseURL: "https://xxxxx-default-rtdb.firebaseio.com",
     projectId: "xxxxx",
     storageBucket: "xxxxx.appspot.com",
     messagingSenderId: "123456789",
     appId: "1:123456789:web:xxxxxxxx"
   };
   ```

### 手順4：index.htmlに貼り付ける

1. GitHubのリポジトリ画面で `index.html` を開き、鉛筆マーク（Edit）をクリック
2. ファイルの中から次の部分を探す（Ctrl+F または Cmd+F で `firebaseConfig` を検索すると見つかりやすいです）

   ```js
   const firebaseConfig = {
     apiKey: "ここに貼り付け",
     authDomain: "ここに貼り付け",
     databaseURL: "ここに貼り付け",
     projectId: "ここに貼り付け",
     storageBucket: "ここに貼り付け",
     messagingSenderId: "ここに貼り付け",
     appId: "ここに貼り付け"
   };
   ```

3. 手順3でコピーした自分の設定値に、そっくりそのまま**置き換える**
4. 画面下の「**Commit changes...**」→「Commit changes」で保存

数分待ってページを再読み込みすれば、Firebaseと繋がった状態になります。

### 動作確認

1. 自分のパソコンでアプリを開き、何か入力する
2. 別のパソコン（またはスマホ、シークレットウィンドウ）で同じURLを開く
3. 入力した内容が反映されていればOK、リアルタイムに共有されています

## セキュリティについて（重要）

テストモードのRealtime Databaseは、**URLと設定さえ分かれば誰でもデータを読み書きできます**。
社内の関係者以外にURLが漏れないよう注意してください。

もしパスワードによるログインなど、より厳格な制限をかけたい場合は追加の設定が必要になるので、
その際はご相談ください。

## Firebaseを設定しない場合

`firebaseConfig` を「ここに貼り付け」のままにしておくと、今まで通り
**そのブラウザだけに保存**される動作になります（共有はされません）。

## 新機能（店舗・保管場所の追加/削除、依頼者記録）

- 店舗一覧の上にある入力欄から、新しいOPEN店舗を自由に追加できます
- 各店舗カード右上の「×」ボタンで、その店舗を削除できます
- カラーチャート／ストーンチャートの在庫欄にある「＋ 保管場所を追加」から、倉庫を自由に追加できます
- 各保管場所カード右上の「×」ボタンで、その保管場所を削除できます（削除すると、その倉庫を引当先にしていた店舗は「倉庫未定」に戻ります）
- カラーチャート・ストーンチャートにも、サンプルオプションと同じく「作成依頼店舗」「依頼者」を記入できます

## 発送管理機能

- 各店舗カードの下部に「発送管理」欄を追加しました
- 発送日をカレンダーから選択できます
- 発送状況を「未発送／発送済み／到着済み」から選べます（色分け表示されます）
